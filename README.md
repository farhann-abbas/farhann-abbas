### 2. Improving Customer Order Fulfillment Reliability — Lean Six Sigma DMAIC

A synthetic-data case study applying the Define, Measure, Analyze, Improve, and Control (DMAIC) methodology to customer order fulfillment.

- Established baseline fulfillment KPIs and documented measurement definitions.
- Conducted descriptive analysis and statistical hypothesis testing.
- Used FMEA to prioritize risks and structure proposed pilot interventions.
- Designed a Power BI dashboard and a process monitoring framework.
- Documented data limitations and distinguished statistical findings from exploratory hypotheses.

**Tools:** Excel, Minitab, Power BI, Git, GitHub

🔗 **[View Lean Six Sigma DMAIC Project](https://github.com/farhann-abbas/lean-six-sigma-order-fulfillment)**
